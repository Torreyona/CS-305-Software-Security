Project Overview
For this project, I worked with Artemis Financial, a company that needed to improve the security of its software application. The goal was to identify security vulnerabilities, protect sensitive information, and make sure the application could communicate securely. This project helped me understand why security needs to be considered throughout the software development process.
1. Client and Software Requirements
My client was Artemis Financial, a financial services company that needed help improving the security of its software. The company wanted to make sure sensitive information was protected and that its application could securely communicate with clients. My task was to identify vulnerabilities, recommend security improvements, and make changes to help protect the application from potential attacks.
2. What I Did Well and the Importance of Secure Coding
I did well at reviewing the application, identifying security concerns, and working through the steps needed to improve its security. I learned how important it is to look for vulnerabilities before software is released instead of waiting until a problem occurs. Secure coding helps protect customer information, prevent unauthorized access, and reduce the risk of costly security incidents. It also helps a company maintain its reputation and build trust with its customers.
3. Challenges and Helpful Parts of the Vulnerability Assessment
One of the more challenging parts of this project was understanding how security tools and code changes worked together. I had to pay attention to the code, certificates, and security configurations to make sure the application was set up correctly. The most helpful part was learning how to identify potential weaknesses and apply security measures to address them. This gave me a better understanding of how software security works in a real-world situation.
4. Increasing Layers of Security
I increased security by implementing secure communication using HTTPS and a certificate, along with a SHA-256 hashing approach for generating a checksum. I also reviewed the application for vulnerabilities and considered how secure coding practices could reduce risks. In the future, I would use tools such as OWASP Dependency-Check, vulnerability scanners, and static code analysis tools to help identify weaknesses. I would then prioritize vulnerabilities based on their severity, likelihood of exploitation, and potential impact before choosing appropriate mitigation techniques.
5. Ensuring Functionality and Security
After making changes to the application, I checked that it continued to function as expected and that the security improvements worked correctly. I used testing and reviewed the application's output to help verify that the changes did not break existing functionality. I also reviewed the code and checked for vulnerabilities after refactoring. Repeating security scans and functional tests is important because changes intended to improve security can sometimes introduce new problems.
6. Helpful Resources, Tools, and Coding Practices
Some of the resources and tools I worked with included Java, Spring Boot, Maven, HTTPS, digital certificates, SHA-256 hashing, and vulnerability-scanning practices. I also learned the importance of reviewing dependencies, testing code after making changes, and following secure coding principles. These skills will be useful in future programming assignments and in a professional software development environment.
7. Skills to Share With Future Employers
I would share my completed Artemis Financial security report and the refactored application code with future employers. These projects demonstrate my ability to review existing software, identify security concerns, make improvements, and test an application after changes have been made. They also show that I understand the importance of protecting sensitive information and considering security throughout the software development process. This experience has helped me build confidence in my ability to approach software development with security in mind.
